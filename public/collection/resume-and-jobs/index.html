Who is the Résumé and job search page for?
You are looking for work. These bots help with the résumé, the applications, and a practice interview. This page is a short list for that job, not the full shelf.
Which bot should I open first?
Start with Résumé and Cover Letter Helper, Career Agent, and The Interviewer. They are the editors' picks, written in the order to try them. The shelf does not have install counts, so this is not a popularity ranking.
How is this different from a category?
