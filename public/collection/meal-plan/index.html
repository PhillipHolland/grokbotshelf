Meal plan

Find by job·14 bots

Dinner is the question. These bots plan meals from what you already have, watch allergies, and make a shopping list. Use this page when you know the job and want a short list, not the whole shelf. Start with What's for Dinner Tonight?, Kitchen, and Meal Planner, the editors' picks, in the order to try them. If those miss the tool or household you have, read Personal Chef, Nourishment, and Sazón before you leave.

Each template is free. Open its page and use Get this bot. The shelf does not install it, and X likes are not a rating. These bots also sit in Food and Creator & Media. Open that category for every template in the group, not only the ones kept for Meal plan. If two bots sound the same, use the first pick once, then add another only if a gap remains.
