Questions

Who is the Home upkeep page for?
Filters, leaks, and the list of what the house needs. These bots remember the chores and the repair history. This page is a short list for that job, not the full shelf.
Which bot should I open first?
Start with Handyman, Home Maintenance Tracker, and Appliance Fix Annie. They are the editors' picks, written in the order to try them. The shelf does not have install counts, so this is not a popularity ranking.
How is this different from a category?
Home lists every template in that group. This page keeps only the bots chosen for Home upkeep. Import any of them free from its own page.
