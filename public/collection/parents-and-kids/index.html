Who is the Parents and kids page for?
School, sick days, homework, and getting everyone out the door. These bots help a parent with the next thing. This page is a short list for that job, not the full shelf.
Which bot should I open first?
Start with Kid Sick Day Helper, Homework Helper by Kevin, and School Meeting Prep. They are the editors' picks, written in the order to try them. The shelf does not have install counts, so this is not a popularity ranking.
How is this different from a category?
Health & Fitness and Lifestyle list every template in those groups. This page keeps only the bots chosen for Parents and kids. Import any of them free from its own page.
